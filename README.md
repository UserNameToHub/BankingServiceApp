#### Взаимодействие сервисов в кластере Kubernetes

В данном кластере Kubernetes развернуты следующие сервисы:
- Account-service
- Cash-service
- Notification-service
- Transfer-service

#### Конфигурация взаимодействия

Сервисы взаимодействуют между собой согласно конфигурации, описанной в манифесте `service.yaml`. В этом файле определены настройки, позволяющие сервисам обмениваться данными внутри кластера.

#### Доступ к сервисам

- **Внутренние запросы:** запросы к внешним сервисам направляются через `nodePort`, который также описан в `service.yaml`.
- **Внешний запрос:** доступ к сервисам осуществляется через конфигурацию, описанную в `ingress.yaml`. Этот файл определяет правила маршрутизации внешних запросов к соответствующим сервисам внутри кластера.

#### Сервисы вне кластера

Следующие сервисы находятся вне кластера и взаимодействуют с ним по определённым конфигурациям:
- UI
- Gateway
- Keycloak

Эти сервисы обеспечивают дополнительный функционал и интеграцию с другими системами.
